# Finding No-No-Namosh II — The Four Trails

Final GitHub Pages build.

## Run
Open `index.html`, or upload the contents of this folder to the root of a GitHub Pages repository.

Keep this exact layout:

- `index.html`
- `game.js`
- `atlas.js`
- `assets/`

## Controls
- Arrow keys / WASD — move
- E — interact / advance dialogue
- Space — attack; swim stroke while in water
- M — world map
- Esc — pause
- L — switch English / Swedish while paused

## Adventure
Aya's Apartment → Riverside Village → Moonshore → Crystalwater Grotto → Windspire Mountain → Ember Peak → Star Temple.

Autosave uses local browser storage.
